# Контекст проекта Niebieski Kot

Этот файл — короткая актуальная сводка для новых задач Codex. Перед работой прочитай его, затем проверяй текущий код и `git status`. Не полагайся на старую длинную переписку, если сведения ниже можно подтвердить файлами проекта.

## Что это за проект

`Niebieski Kot` — адаптивный демонстрационный сайт котокафе в Ополе.

- Production: https://niebieski-kot.vercel.app/
- GitHub: https://github.com/Paremik/Niebieski_Kot
- Основной язык сайта — польский.
- Также поддерживаются русский и английский.
- Основная ветка — `main`; Vercel публикует изменения из неё.

## Технологии

- React 18 и JavaScript/JSX.
- Vite 6.
- React Router 7.
- Tailwind CSS/PostCSS.
- Vercel Functions в каталоге `api/`.
- Upstash Redis для постоянного хранения редактируемого контента.
- Менеджер пакетов — `pnpm`; Node.js 22+.

## Текущее состояние

- Работают главная страница `/`, меню `/menu`, профили `/koty/:slug` и админка `/admin`.
- Неизвестные маршруты показывают локализованную страницу 404.
- Карточки и профили созданы для Luna, Mochi и Pixel.
- На сайте есть меню, бронирование, правила, FAQ, события, поддержка котов и демонстрационный ассистент.
- Переключение PL/RU/EN работает между страницами и сохраняет выбранный язык.
- Админ-панель локализована и редактирует расписание, цены, события, места и данные котов.
- Контент админки хранится в Upstash Redis и загружается публичным сайтом через `/api/content`.
- После сохранения админка всегда запрашивает свежие данные, чтобы не показать закэшированную старую версию.
- Последние важные исправления: переход на React Router, восстановление импортов React и переводов, исправление белого экрана, production-админка и свежая загрузка контента.

## Архитектурные решения

- Маршрутизация находится в `src/AppRoutes.jsx`; не возвращать ручную маршрутизацию.
- Глобальный редактируемый контент предоставляет `src/content/SiteContentProvider.jsx`.
- Исходные и нормализованные данные админки находятся в `src/data/adminData.js`.
- API контента находится в `api/content.js`.
- Авторизация находится в `api/auth/` и `api/_lib/auth.js`.
- Redis-клиент находится в `api/_lib/redis.js`.
- Сессия админки хранится в подписанной cookie `HttpOnly`, `Secure`, `SameSite=Strict` со сроком 8 часов.
- Изменения контента защищены проверкой авторизации, same-origin, размера запроса, валидацией и номером ревизии. Конфликт ревизий возвращает HTTP 409.
- Чтение контента допускает короткое CDN-кэширование; запрос с `?fresh` отключает кэш.
- Известные маршруты получают точки входа после сборки, а `vercel.json` обеспечивает SPA fallback.

## Переменные окружения

Для рабочей production-админки нужны значения в Vercel. Никогда не записывай их значения в репозиторий или этот файл.

- `ADMIN_PASSWORD`
- `SESSION_SECRET`
- `UPSTASH_REDIS_REST_URL` или `KV_REST_API_URL`
- `UPSTASH_REDIS_REST_TOKEN` или `KV_REST_API_TOKEN`

## Правила изменений

- Любой новый интерфейсный текст сразу добавлять на PL, RU и EN.
- Использовать существующую систему `src/i18n/` и функцию `tr()`; не переводить DOM вручную.
- Не ломать сохранение языка при переходах между маршрутами.
- Не помещать пароли, токены, cookie или другие секреты в код, логи, коммиты и документацию.
- Перед изменением схемы контента учитывать нормализацию, валидацию и обратную совместимость сохранённых данных Redis.
- Не заменять постоянное хранение админки обратно на `localStorage`.
- Сохранять доступность модальных окон: управление фокусом, Escape и клавиатурную навигацию.
- После изменений проверять как минимум `pnpm test` и `pnpm build`; изменения интерфейса дополнительно проверять в браузере на мобильной и настольной ширине.
- После публикации проверять production-маршруты и консоль браузера.

## Основные файлы

- `App.jsx` — главная страница.
- `AdminPage.jsx` — интерфейс админки.
- `MenuPage.jsx` — меню.
- `CatProfilePage.jsx` — профили котов.
- `src/AppRoutes.jsx` — маршруты и метаданные.
- `src/i18n/` — переводы PL/RU/EN.
- `src/data/` — исходные данные сайта.
- `api/` — backend админки и контента.
- `tests/` — проверки переводов, маршрутов, данных и рендера.
- `vercel.json` — маршрутизация и заголовки Vercel.

## Что ещё не считается готовым реальным бизнес-функционалом

- Данные кафе, адрес, фотографии и сведения о животных всё ещё демонстрационные, пока владелец не подтвердит их.
- Форма бронирования и чат-ассистент остаются демонстрационными, если их backend отдельно не реализован.
- Поддержка котов не должна принимать реальные платежи без официального платёжного оператора.
