# Niebieski Kot

Адаптивный сайт концептуального котокафе в Ополе. Проект показывает, как посетитель знакомится с котами, смотрит меню, выбирает язык, читает правила и события, отправляет демонстрационную заявку на столик и поддерживает котов.

![Превью меню Niebieski Kot](https://niebieski-kot.vercel.app/images/menu-latte.webp)

- Профиль Mochi: [niebieski-kot.vercel.app/koty/mochi](https://niebieski-kot.vercel.app/koty/mochi)

## Задача проекта

Создать тёплый и понятный сайт котокафе, который помогает человеку быстро ответить на вопросы перед первым визитом: кто живёт в кафе, что есть в меню, нужны ли правила и бронирование, какие проходят события и как можно поддержать животных.

## Возможности

- адаптивная главная страница с блоками о кафе, котах, визите и событиях;
- карточки и подробные профили Luna, Mochi и Pixel;
- отдельное меню с категориями, ценами и фото-каруселью;
- польский, русский и английский языки с сохранением выбора между маршрутами;
- FAQ и правила посещения: дети, аллергии, своя еда и животные;
- форма бронирования и демонстрационный чат-ассистент;
- события: йога с котами, игры, мастер-классы и дни усыновления;
- раздел поддержки котов, список необходимых вещей и виртуальные варианты помощи;
- локальная админ-панель `/admin/` для демонстрационного редактирования расписания, цен, событий, мест и данных котов;
- статические маршруты `/menu/` и `/koty/:slug/`, совместимые с Vercel и локальным preview-сервером.

## Технологии

- React 18;
- Vite 5;
- Tailwind CSS и PostCSS;
- Lucide React для иконок;
- JavaScript (JSX);
- pnpm;
- Vercel для production-деплоя.

## Локальный запуск

Требуется Node.js 18+ и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте [http://localhost:5173](http://localhost:5173). Для проверки production-сборки:

```bash
pnpm build
pnpm test
```

После `build` скрипт `scripts/postbuild-routes.mjs` создаёт статические entry points для `/admin/`, `/menu/` и профилей котов.

## Структура проекта

```text
App.jsx                совместимый home-контейнер и локализация главной
src/pages/             точки входа HomePage, MenuPage и CatProfilePage

src/data/              данные котов, правил, FAQ, событий и меню
MenuPage.jsx           реализация страницы меню
CatProfilePage.jsx     реализация профилей Luna, Mochi и Pixel
BookingModal.jsx       форма бронирования
SupportModal.jsx       демонстрационная поддержка котов
AdminPage.jsx          локальная админ-панель
LanguageSelect.jsx     общий переключатель языка
main.jsx               маршрутизация страниц
styles.css             глобальные стили и порядок секций
public/images/         изображения меню
scripts/               postbuild и smoke-тесты
vercel.json            rewrites для Vercel
```

## Демонстрационные данные

Кофейня, адрес, фотографии, имена и истории котов, расписание, цены, события, бронирование, поддержка и админ-панель являются демонстрационными. Админ-панель хранит изменения только в `localStorage` текущего браузера и не изменяет публичную базу данных.

Перед настоящим запуском нужно подключить подтверждённый адрес и часы работы, реальные фотографии и данные животных, backend для бронирований, авторизацию админ-панели, базу данных и официальный платёжный оператор.
