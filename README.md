# Niebieski Kot

Котокафе в Ополе с меню, профилями котов, бронированием, событиями и разделом поддержки.

## Возможности

- адаптивная главная страница на React + Vite;
- отдельное меню с категориями и ценами;
- профили Luna, Mochi и Pixel;
- форма бронирования в демонстрационном режиме;
- FAQ и правила первого визита;
- календарь событий;
- поддержка котов и список необходимых вещей;
- переключатель польского, русского и английского языков;
- локальная админ-панель: `/admin/`;
- локальные маршруты `/menu/` и `/koty/:slug/`.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:5173/`.

## Сборка и проверка

```bash
pnpm build
pnpm test
```

После сборки скрипт создаёт статические entry points для `/admin/`, `/menu/` и страниц котов, поэтому они работают и в локальном статическом просмотре.

## Важно

Контент, адрес, фотографии, цены, расписание и формы пока являются демонстрационными. Админ-панель хранит изменения только в `localStorage` текущего браузера. Перед настоящим запуском нужны авторизация, база данных, серверная обработка бронирований и официальный платёжный оператор.
