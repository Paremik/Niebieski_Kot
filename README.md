# Niebieski Kot

Адаптивный сайт концептуального котокафе в Ополе. Проект показывает, как посетитель знакомится с котами, смотрит меню, выбирает язык, читает правила и события, отправляет демонстрационную заявку на столик и поддерживает котов.

![Превью меню Niebieski Kot](https://niebieski-kot.vercel.app/images/menu-latte.webp)

## Задача проекта

Создать тёплый и понятный сайт котокафе, который помогает человеку быстро ответить на вопросы перед первым визитом: кто живёт в кафе, что есть в меню, нужны ли правила и бронирование, какие проходят события и как можно поддержать животных.

## Возможности

- адаптивная главная страница с блоками о кафе, котах, визите и событиях;
- карточки и подробные профили Luna, Mochi и Pixel;
- отдельное меню с категориями, ценами и фото-каруселью;
- мгновенное переключение польского, русского и английского без перезагрузки, в том числе в формах и админке; выбор сохраняется между маршрутами;
- FAQ и правила посещения: дети, аллергии, своя еда и животные;
- форма бронирования и демонстрационный чат-ассистент;
- события: йога с котами, игры, мастер-классы и дни усыновления;
- раздел поддержки котов, список необходимых вещей и виртуальные варианты помощи;
- защищённая админ-панель `/admin/` для редактирования расписания, цен, событий, мест и данных котов;
- хранение редактируемого контента в Upstash Redis через Vercel Functions;
- React Router для `/`, `/menu`, `/koty/:slug` и `/admin`; неизвестные адреса показывают локализованную страницу 404.

## Технологии

- React 18;
- React Router 7;
- Vite 6;
- Tailwind CSS и PostCSS;
- Lucide React для иконок;
- Vercel Functions для API админки и публичного контента;
- Upstash Redis для постоянного хранения редактируемых данных;

- pnpm;
- Vercel для production-деплоя.

## Локальный запуск

Требуется Node.js 22+ и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте [http://localhost:5173](http://localhost:5173). Для проверки production-сборки:

```bash
pnpm build
pnpm test
pnpm preview
```

Предпросмотр доступен по [http://localhost:4173](http://localhost:4173). Используйте Vite preview, а не обычный файловый HTTP-сервер: для неизвестных маршрутов нужен SPA fallback. После `build` скрипт `scripts/postbuild-routes.mjs` дополнительно создаёт статические точки входа для известных страниц.

## Демонстрационные данные

Кофейня, адрес, фотографии, имена и истории котов, расписание, цены, события, бронирование и поддержка являются демонстрационными, пока владелец не подтвердит реальные данные. Админ-панель уже работает в production: после входа она сохраняет редактируемый контент в Upstash Redis, а публичный сайт загружает эти данные через `/api/content`.

Перед настоящим запуском нужно подключить подтверждённый адрес и часы работы, реальные фотографии и данные животных, backend для бронирований и официальный платёжный оператор. Значения `ADMIN_PASSWORD`, `SESSION_SECRET`, `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` должны храниться только в переменных окружения Vercel и не должны попадать в репозиторий.

## Проверки

`pnpm test` проверяет все поля профилей и FAQ на наличие трёх переводов, отрисовку страниц и модальных окон на PL/RU/EN, неизвестные адреса, порядок блоков, даты и время бронирования, а также повреждённые данные админки. Тесты выполняются через Node Test Runner и React server rendering; они дополняют, но не заменяют проверку интерактивности в браузере.

Новый интерфейсный текст добавляйте в `src/i18n/` сразу на трёх языках и выводите через `tr()`. Не изменяйте текстовые узлы DOM и не перезагружайте страницу при смене языка. Произвольный текст, введённый в локальном редакторе, автоматически не переводится.
